      How to use

      1. Open this page once while online so it can work offline, then add it to your home screen from the browser menu.
      2. Add an entry: tap +, type the amount, then Save expense. The top category is already chosen.
      3. NFC card: with an app such as NFC Tools, write a URL record for this page’s address followed by ?a=1 (expense) or ?i=1 (income). Test it on your phone; tap behaviour depends on the phone and browser.
      4. Review entries in Ledger, set a budget above, and download a backup regularly.
