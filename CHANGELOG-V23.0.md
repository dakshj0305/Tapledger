# VOLTURA V23.0 — vivid depth

- Added a dedicated local `vivid-depth.css` visual layer for atmospheric depth, clearer elevation, responsive card surfaces and a luminous scroll-progress indicator.
- Added `vivid-depth.js` for pointer-aware 3D card tilt and specular highlight tracking on fine-pointer devices.
- Preserved native scrolling, finance workflows, keyboard operation, touch layouts, offline behavior and reduced-motion preferences.
- No WebGL, external runtime, CDN, React migration or financial schema change.
- Updated service-worker cache identity and precache for the new assets.
