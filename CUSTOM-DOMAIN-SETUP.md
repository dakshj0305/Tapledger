# Custom domain — not configured

The current published project address is `https://dakshj0305.github.io/Tapledger/`. The VOLTURA package must not include a `CNAME` file or a custom-domain canonical URL while `voltura.finance` is unregistered.

When you own and configure a domain later, add it in GitHub Pages Settings → Pages and configure the DNS records shown by GitHub. Only then create the matching root `CNAME` file and rebuild the manifest scope/start URL for that domain. Browser storage is origin-specific; export and restore a JSON backup when moving between origins.
