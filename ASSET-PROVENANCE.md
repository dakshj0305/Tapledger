# Asset provenance

- `icons/voltura-mark.svg` is an original, single-colour geometric V mark authored for this project. The same vector geometry is reused in the inline app symbol and raster PWA icons.
- `icon-192.png`, `icon-512.png`, `icon-192-maskable.png` and `icon-512-maskable.png` are generated from that SVG using a matte volt-lime tile and dark mark. Maskable variants keep the mark within a conservative centered safe zone.
- UI icons are inline SVG symbols authored in `index.html`; no icon CDN or stock image dependency is used.
- The optional `KineticGrid.tsx` attachment was not present in the source bundle and is not included or claimed as implemented.
