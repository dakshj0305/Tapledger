# VOLTURA motif system v20.0 — V-cut / signal

## Creative direction: loud minimalism

VOLTURA is an editorial finance workspace: bold typographic hierarchy, open mineral-paper canvas, graphite structure and one high-voltage chartreuse signal. It is intentionally not a generic banking dashboard, crypto terminal or soft SaaS card grid.

## The single motif: V-cut / controlled flow

The angular V in the VOLTURA mark is the product's single visual signature. A clipped corner carries that geometry into the active navigation state and primary focal surfaces. The motif represents a decision point in a financial flow: capture, classify, review.

Use the motif as a structural cue, not a repeated lightning illustration:
- Brand mark: solid angular V, with a small clipped signal facet.
- Navigation: selected destination has a crisp clipped leading corner.
- Dashboard: the net-cashflow field is the dominant signal; a quiet oversized V geometry sits behind it.
- Quick capture: direct, amount-first task surface; selected category and save action use the signal colour.
- Supporting views: restrained clipped geometry only at key action or section moments.

## Palette

- Signal: `#D9FF36` — primary action, selected state, one key financial focal point.
- Graphite: `#101612` — brand structure and high-contrast surfaces.
- Mineral paper: `#F1F0E8` — light canvas.
- Chalk: `#FBFAF5` — light surface.
- Deep graphite: `#101612` — dark canvas.
- Dark surface: `#18211B` — dark panels.

Semantic colours remain distinct and labelled. Income and expense are never distinguished by colour alone.

## Composition

- Strong, oversized display type only at the start of a view or for a key financial value.
- Tabular numerals for money and percentages.
- Matte, flat surfaces; crisp borders; no broad gradients, glass, blur, glow or soft decorative shadows.
- Not every section belongs in a card. Use open space, editorial rules and structured rows.
- Use square/near-square corners for the main visual language; reserve the clipped corner for the signature.
- Chart colours are semantic and consistent in light and dark themes.

## Interaction and accessibility

Respect reduced motion and forced-colors. Maintain visible keyboard focus, semantic labels, 44px minimum mobile targets, safe-area insets and no horizontal overflow at 320px. Inputs remain at least 16px on mobile.

## Data and technical boundary

The V20 visual layer is presentation-only. Preserve IndexedDB `tapledger-db`, version 3, stores, keys, indexes, migration marker, paise arithmetic, backup compatibility, `?a=1` / `?i=1`, and `/Tapledger/` paths. No financial data is sent to external services.
