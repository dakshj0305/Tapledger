# VOLTURA visual motif system v18.1

The visual anchor is a single solid angular V mark, repeated in the inline app symbol, favicon and PWA icons. Use one colour only; keep the mark clear at small sizes.

- Solid colour fields; no gradients, glassmorphism, blur, noise or glow.
- Matte working surfaces without soft shadows.
- One crisp top/left hairline facet on the main action and mark only.
- One direction for the controlled highlight; no unrelated stars, blobs, random gradients or decorative 3D objects.
- Large amounts use tabular numerals.
- All visual ornament is suppressed under reduced motion; the NFC sheet remains static.
