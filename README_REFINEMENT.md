# VOLTURA — Cinematic Refinement

This package contains a refined version of the supplied standalone VOLTURA finance landing-page prototype.

## Open
1. Extract this ZIP.
2. Open `code.html` in a modern browser.
3. For the intended typography and motion, allow network access to the pinned Aspekta webfont, Tailwind CDN, and GSAP 3.12.5 CDN.

## Included refinements
- Aspekta variable font stack with fallbacks.
- High-contrast dark palette, restrained borders, consistent focus rings.
- Responsive native mobile navigation.
- Four-face 3D cube hero retained, with reduced-motion fallback.
- Continuous project-specific ticker with inline SVG punctuation.
- GSAP ScrollTrigger ticker speed response and scroll-linked reveals.
- Existing case-study and calculator content retained.
- Existing quick-entry interactions and finance prototype logic retained.

## Important scope
This is the supplied `code.html` prototype, not the user's local `C:\Users\DELL\Desktop\v_19` application. The actual v19 source was not included in the uploaded ZIPs. Do not overwrite v19 with this file. Integrate only after comparing against the real app source and protecting its storage, migrations, and quick-entry behavior.

The calculator's percentage assumptions and example balances are illustrative prototype content. They are not validated financial calculations or live account data.
