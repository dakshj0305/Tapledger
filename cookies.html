COOKIES & BROWSER STORAGE

Cookies & Local Storage

Voltura uses essential browser storage for its local-first functionality and does not add tracking or advertising cookies.

1. Does Voltura set cookies?

The supplied Voltura application code does not set, read or use cookies. It does not include advertising cookies, analytics cookies or social-media tracking code. For this reason, the application does not display a cookie-consent banner for non-existent application cookies.

2. What browser storage does Voltura use?

  • IndexedDB: stores your transactions, accounts, budgets and small application settings in the current browser profile.
  • Cache Storage: the service worker caches static application files so the interface can load offline after the first successful visit.
  • URL parameters: ?a=1, ?i=1 and the legacy ?add=1 are action shortcuts. Voltura removes the action query from the visible address bar after reading it. Do not place personal financial details in URLs.

These browser storage mechanisms are not cookies. They are essential to the local-first application's core functions.

3. Third-party services

The app is delivered from its configured web host (currently intended to be Netlify). The host receives normal website requests and may process technical request metadata under its own terms. The V27 interface does not include voice recognition or request microphone access.

4. How to clear browser data

Use your browser's site settings for the Voltura site to clear cookies and site data, including IndexedDB and Cache Storage. Clearing site data may permanently erase transactions, accounts and budgets. Legacy records from older versions may also be present. Export a JSON backup first. The in-app delete-all action clears Voltura financial records but retains the application shell needed to continue using the site.

5. Policy changes

If a future release adds analytics, advertising, non-essential cookies or other tracking technologies, this policy must be updated and an appropriate consent mechanism must be implemented before those technologies run. No such tracker is included in the source audited for this release.
